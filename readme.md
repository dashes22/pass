# Система авторизации
Учебный проект. Регистрация и вход пользователей с проверкой надёжности пароля и защитой от подбора.

## Как запустить
1. Установить зависимости:
   npm install
2. Запустить сервер:
   node server.js
3. Открыть в браузере:
   http://localhost:3000

## Файлы проекта
### server.js
Серверная часть. Работает на Node.js и отвечает на запросы из браузера.

Что делает:
- подключается к базе данных pass.db
- создаёт таблицу users, если её ещё нет
- принимает запросы от браузера и отвечает на них
- проверяет логин и пароль при регистрации
- хеширует пароль перед сохранением в базу
- проверяет пароль при входе
- блокирует вход после нескольких неудачных попыток

Внутри описаны три адреса, на которые браузер отправляет запросы:
- POST /check-login - проверяет, свободен ли логин
- POST /register - создаёт нового пользователя
- POST /login - проверяет логин и пароль для входа
- 
Также внутри есть несколько вспомогательных функций:
- validatePassword - проверяет, подходит ли пароль по требованиям
- isCommonPassword - проверяет, не входит ли пароль в список частых
- hashPassword - превращает пароль в хеш перед сохранением
- verifyPassword - сравнивает введённый пароль с сохранённым хешем
- checkBlock - проверяет, не заблокирован ли пользователь
- addFailedAttempt - добавляет неудачную попытку и, если нужно, ставит блокировку
- generatePepper - создаёт случайную строку (pepper) для усиления хеша

### index.html
Страница, которую видит пользователь в браузере.

Что содержит:
- заголовок «Аккаунт»
- поле для ввода логина
- поле для ввода пароля
- подсказку о требованиях к паролю
- скрытое поле «Повторите пароль» (появляется только при регистрации)
- кнопку «Зарегистрироваться»
- кнопку «Войти»
- пустой блок, куда выводятся сообщения об успехе или ошибке

### style.css
Стили страницы. Отвечает за внешний вид.

Что оформляет:
- фон страницы
- карточку по центру экрана с тенью и скруглёнными углами
- поля ввода и их подсветку при нажатии
- кнопки и их цвета
- подсказку под паролем
- блок с сообщениями
- адаптацию под узкие экраны (на телефоне кнопки становятся в столбик)

### script.js
Клиентская часть. Работает в браузере и общается с сервером.

Что делает:
- читает то, что пользователь ввёл в поля
- отправляет запросы на сервер через fetch
- показывает результат: успех или ошибку
- прячет и показывает поле «Повторите пароль»
- проверяет, что логин свободен, перед тем как просить повтор пароля
- обрабатывает нажатие Enter в полях
- очищает поля после успешной регистрации или входа

### test.js

Юнит-тесты. Это отдельный файл, который проверяет, что вся логика работает правильно.

Что проверяет:
- валидация пароля (длина, заглавная буква, строчная буква, цифра, спецсимвол, частые пароли)
- валидация логина (пустой, из пробелов, короткий, нормальный)
- логика блокировки (10 секунд, 30 секунд, 5 минут, удвоение, максимум 1 час)

Запуск:
node test.js

В консоли для каждого теста пишется PASS или FAIL, а в конце - общий результат: сколько прошло, сколько провалилось.

### package.json

Служебный файл. В нём перечислены зависимости, которые нужны проекту, и команды для запуска.

Что внутри:
- список библиотек (express, sqlite3, argon2, cors, @vks-dev/common-password)
- команда npm start - запуск сервера
- команда npm run dev - запуск сервера с автоперезагрузкой

### pass.db

Файл базы данных SQLite. В нём хранятся данные.

Таблица users:
- id - номер пользователя
- login - логин
- password - хеш пароля
- pepper - случайная строка для усиления хеша
- created_at - дата регистрации

## Требования к паролю

Пароль должен:
- быть не короче 8 символов
- содержать хотя бы одну заглавную букву
- содержать хотя бы одну строчную букву
- содержать хотя бы одну цифру
- содержать хотя бы один специальный символ (!@#$%^&* и другие)
- не быть в списке частых паролей

## Блокировка при подборе пароля

Если пользователь несколько раз вводит неправильный пароль, вход временно блокируется:

- 1-я неудачная попытка - 10 секунд
- 2-я - 30 секунд
- 3-я - 5 минут
- 4-я и дальше - каждый раз удваивается, но не больше 1 часа

Если после последней попытки прошло 5 минут, счётчик сбрасывается.
